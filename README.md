Tracking the Untrackable – ARGUS-X

Project Overview

ARGUS-X is a computer vision project designed for object detection and tracking in video footage.

The project uses YOLO and BoT-SORT for object detection and tracking.

Features

- Object Detection
- Object Tracking
- Video Processing
- Computer Vision
- Real-time Tracking (if supported by the application)

Technologies Used

- Python
- YOLO
- BoT-SORT
- OpenCV
- Streamlit
- Jupyter Notebook

Project Structure

Tracking-the-Untrackable/
│
├── app.py
├── engine.py
├── argus.ipynb

Installation

Clone the repository:

git clone https://github.com/nandinikpkaribasappapatil-art/Tracking-the-Untrackable.git

Go to the project folder:

cd Tracking-the-Untrackable

Install dependencies:

pip install -r requirements.txt

Run the Application

streamlit run app.py
